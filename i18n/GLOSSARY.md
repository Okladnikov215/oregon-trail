# Oregon Trail 1978 - Glossary

## Game Context
This is a text-based adventure game about American pioneers traveling 
the Oregon Trail from Independence, Missouri to Oregon in 1848.
The player manages a wagon party, buys supplies, hunts, and survives 
diseases, river crossings, and attacks.

## Key Terms
- RIDERS = всадники (NOT кавалерия, NOT выпасы)
- BANDITS = бандиты, разбойники
- OXEN = волы (тягловые животные)
- WAGON = фургон, повозка
- FORT = форт (укреплённый торговый пост)
- RATION = паёк, рацион
- DISENTERY = дизентерия
- TYPHOID = брюшной тиф
- MEASLES = корь
- CHOLERA = холера
- INDEPENDENCE = Индепенденс (город в Миссури)
- OREGON = Орегон (штат назначения)
- MISSOURI = Миссури (штат отправления)
- COLUMBIA RIVER = река Колумбия
- SNAKE RIVER = река Снейк
- GREEN RIVER = река Грин-Ривер
- KANSAS RIVER = река Канзас
- BIG BLUE RIVER = река Биг-Блу
- PACIFIC CITY = Пасифик-Сити (конечная точка)
- DODGE CITY = Додж-Сити (город на Диком Западе)
- COLT .45 = Кольт .45 (револьвер)
- DOC BLANCHARD = Док Бланшард (имя доктора)
- MOUNTAIN PASS = горный перевал
- HUNTING = охота (NOT рыбалка)
- BULLETS = пули, патроны
- SPARE PARTS = запасные части
- CLOTHING = одежда
- FOOD = еда, провизия

## Tone
- Use natural, conversational Russian
- 19th century American frontier atmosphere
- Short, punchy phrases for game messages
- Preserve ALL CAPS where original is ALL CAPS
- Keep punctuation style (--, ---, !!!) from original

## Common Original Typos to Watch For
- "OOT" is likely "GOT" (typo in original)
- "M0RE" is "MORE" (zero instead of letter O)
- Preserve intentional typos only if they seem deliberate
