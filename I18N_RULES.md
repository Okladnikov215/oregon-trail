# I18N Rules

Target language: Russian.

Rules:
- Translate only human-visible text: UI strings, dialogues, descriptions.
- Do NOT change variable names, function names, class names, identifiers, imports, logic, keys, or file structure.
- Do NOT translate placeholders such as {}, {name}, %s, %d, {0}, {1}.
- Preserve JSON/YAML/PO syntax strictly.
- Preserve escaping, line breaks, quotes, indentation.
- Keep technical identifiers unchanged.
